# Design examples

These examples illustrate decisions rather than prescribe one visual style.

| Brief | Useful response | Failure to avoid |
| --- | --- | --- |
| Education partnership site with event imagery and an interactive market map | Build a credible event-led opening, partnership action and browsable market information. Keep requested purposeful motion accessible. | Replace the actual brief with a generic monochrome startup landing page. |
| Electronics storefront | Use coherent product imagery, stable cards, visible prices and useful discovery. | Bury search and catalog entry below a decorative hero. |
| Full reference-led corporate site | Establish a convincing visual slice and the required internal page families. | Call a single page with section anchors a complete site. |
| Standalone pixel-art workspace | Keep the chosen metaphor and make the operator's controls/status clear. | Substitute an unrelated chat dashboard because it is easier to build. |
| Content-only edit | Preserve the visual language and compare actual text wrapping. | Introduce a new font/theme and shift the composition unnecessarily. |

A numerical claim supplied as an example in a brief is not automatically a verified company fact. A prototype is not a working integration, and a reviewer accepting one component is not client approval of the whole product.
