# Patterns are clues, not bans

| Candidate | When it becomes a problem | Useful replacement |
| --- | --- | --- |
| Animated particles, canvas background, cursor glow | Distracts from the task, reduces readability, runs continuously without communicating state | Real product/event imagery, an intentional static composition, or no background layer; stop the underlying loop/listeners |
| Gradient heading and glow on every control | Makes all content equally emphatic or hides text against images | Solid readable text and a deliberate primary-action hierarchy; retain brand gradients where justified |
| Every item in the same card | Treats incomparable information as equivalent, wastes space or hides relationships | Rows, grouped lists, comparison tables, editorial sections, or cards only for actual independent objects |
| Giant hero and repeated empty sections | Delays the catalog, form or work queue | Shorter task-led opening and content density appropriate to the product |
| Many pills and generic icons | Adds decoration without useful taxonomy or action | Concrete labels, real product thumbnails, or simple text grouping |
| Fake live status or simulated activity | Claims work, connectivity or submission without evidence | Explicit queued, blocked, demo, saved-local, failed or completed state from the actual source |
| Beige/white minimalism after cleanup | Erases identity or useful explanation | Restore purposeful brand color, differentiated hierarchy and actual content |


## Context changes the decision

A partnership site may explicitly require animated counters, partner motion and an interactive market map. Those requirements are not automatically slop. A playful office workspace can retain pixel art while making work states truthful.

When removing a decorative effect, trace its DOM, CSS, event listeners and animation lifecycle. Hiding a canvas can leave a running loop. Where source access is limited, document the limit rather than claiming full removal.

Simplification must retain meaning: real logo variants, understandable scan/actions, useful explanations, sufficient color and readable density. Sparse, empty screens can be as unhelpful as overdecorated ones.
