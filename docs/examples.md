# Copy-ready prompts

Choose the primary skill for the task. Add the actual route, screenshot, repository or reference available to your agent. These are prompts, not claims that a particular design has already been improved.

## Create a product-specific interface

```text
Use $product-ui-direction to design this booking app's search and result flow.
Inspect the existing brand assets and real content first. Prioritize choosing
the right booking, then define typography, image treatment and action hierarchy.
Build a convincing mobile and desktop slice before expanding the direction.
```

## Remove generic UI without erasing identity

```text
Use $ui-deslop to fix this service website. Keep the blue brand, supplied photos,
useful explanations and working form. Find the actual sources of visual clutter
and weak hierarchy. Remove unjustified effects at source, including active loops,
then compare the same pages before and after.
```

## Review only

```text
Use $ui-deslop to review this dashboard. Do not edit files. Report the most useful
findings with exact screen/state, user impact and a concrete replacement.
Distinguish reproduced failures from aesthetic judgement.
```

## Follow a reference and deliver the right scope

```text
Use $reference-led-web-design with the attached reference. I need a complete
corporate website with service listings, service detail, about, contact and enquiry
pages. Inspect the reference's first viewport, navigation and mobile structure.
Use our brand and assets. Compare matching renders and state deliberate differences.
```

## Improve product variants and account UX

```text
Use $commerce-ux-refinement on this store's product and account flows. Color and
storage selection should be obvious, preserve context and update the correct
price, image and stock. Simplify registration and show the signed-in user's photo
when available. Use fixtures or a non-purchasing test path.
```

## Make an operational panel useful

```text
Use $operational-dashboard-ux on this admin screen. Operators need a selected
two-day range, an explicit segment filter and a readable work list. Keep unknown
values distinct from zero. Ensure the totals describe the same subset and that
saved/running/completed badges reflect the underlying state.
```

## Check a change without redesigning everything

```text
Use $responsive-ui-verification after this content edit. Preserve the current
visual language. Compare the same route at narrow mobile and desktop widths,
including the longest supported translation and the relevant validation state.
Report what was actually checked and any browser/device limits.
```

## Combine skills when the task warrants it

For a substantial redesign, `product-ui-direction` can establish the direction and
`responsive-ui-verification` can verify the changed surfaces. For a small defect,
one focused skill is often sufficient. Do not load every skill as a universal ritual.
